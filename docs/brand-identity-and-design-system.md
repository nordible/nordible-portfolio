## 4. Typography & Visual Hierarchy (*Typografie*)

Our typographic system is optimized for rapid scanning (F-pattern) and technical clarity:

- **Headings (`font-heading`):** `Sora`, sans-serif (Weights: 700, 800) – Modern, geometric, authoritative.
- **Body Text (`font-sans`):** `Inter`, sans-serif (Weights: 400, 500, 600) – High legibility at small sizes, optimal x-height.
- **Micro-Data / Code (`font-mono`):** `Space Mono`, monospace (Weights: 400, 700) – Badges, metric indicators, timestamps.

## 5. UI/UX Behavioral Guidelines

1. **Zero-Scroll Lateral Anchoring:** Decorative elements must not push primary conversion triggers down the viewport.
2. **Accessible Contrast (WCAG AAA):** High contrast ratios for all critical text and actionable controls.
3. **Ergonomic Controls (Fitts's Law):** Mobile touch targets minimum 44px; primary actions kept within thumb-reach zones.
4. **Cognitive Chunking (Miller's Law):** Core values and packages structured strictly in digestible 3-to-4 item triads.
